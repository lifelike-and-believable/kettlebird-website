# Images

Place your website images in this directory.

## Recommended File Formats

- **JPG/JPEG** - For photographs and complex images
- **PNG** - For images with transparency
- **SVG** - For logos, icons, and simple graphics
- **WebP** - Modern format with better compression (recommended)

## Naming Conventions

Use descriptive, lowercase names with hyphens:
- `hero-background.jpg`
- `logo-primary.svg`
- `team-member-1.jpg`

## Optimization Tips

- Compress images before uploading
- Use appropriate dimensions (don't upload 4K images if you only need 800px)
- Consider using lazy loading for below-the-fold images
