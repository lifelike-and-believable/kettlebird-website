# Correct the panels

<!-- docs/product/stories/comic-reader-flip-and-panels/correct-the-panels.md. Story 5 of epic-comic-reader-flip-and-panels. -->

As Star, I want to see the panels the site found on a page and fix any that are wrong by working on the page itself, so that panel-by-panel reading follows my layout.

## Acceptance criteria

- In the editor, Star opens a page and sees the picture with each panel drawn on it as a numbered box.
- Star can move and resize a box by dragging it, draw a new box, remove one, and change the reading order, all on the picture; no numbers to type.
- Star can clear a page's panels so that it is always shown whole.
- Star can preview the page panel by panel before publishing.
- Changes are saved like any other edit and go live when the chapter is published; finding the panels again never undoes them.
- The tool works with a mouse or a trackpad, and every action also has a keyboard way to do it.
