�� KEY FEATURES SPECIFIED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 🖼️  IMAGE PORTFOLIO
     • Responsive grid with category filtering
     • PhotoSwipe v5 lightbox for full viewing
     • Lazy loading with blur-up placeholders
     • Hand-drawn Polaroid frames with tape accents
     • Sanity CDN optimization (WebP, responsive sizes)

  2. 📖 COMIC READER
     • Frame-by-frame panel navigation using panzoom
     • Panel coordinates stored in Sanity (x, y, width, height %)
     • Keyboard controls (arrows, space, F, Escape)
     • Touch gestures (swipe, pinch, double-tap)
     • Multiple reading modes (guided, page, vertical scroll)
     • Progress tracking with localStorage
     • Fullscreen mode

  3. 📚 WRITTEN WORKS
     • 3D page-flip animation (react-pageflip)
     • Realistic book-turning effects
     • Touch/swipe support for mobile
     • Bookmark functionality
     • Table of contents navigation
     • Night/day reading modes
     • Accessibility toggle to plain scroll view

  4. 🎨 RADIAL NAVIGATION
     • CSS trigonometry circular layout
     • Staggered flutter animation on open
     • Framer Motion layout transitions
     • Transforms to horizontal navbar on scroll
     • 5-7 menu items maximum
     • Keyboard navigation and ARIA support

  5. 🛍️  COMMERCE/MERCHANDISE
     • Ko-fi integration for payments (5% fee or 0% with Gold)
     • Product catalog with filtering
     • Shopping cart and checkout
     • Inventory tracking (optional)
     • Secure SSL/HTTPS

  6. 💼 COMMISSIONS
     • Custom commission info page with pricing tiers
     • Google Forms for commission requests
     • File upload for reference images
     • Trello board for public queue visibility
     • Terms of service and FAQ
     • Will/Won't draw boundaries

  7. 🎨 HAND-DRAWN VISUAL DESIGN
     • Textured paper background with grain patterns
     • UPA-style flat color palette (burnt orange, teal, coral)
     • SVG filters (roughen, ink bleed, watercolor, grain)
     • Sketchy borders using border-radius tricks
     • Hand-drawn typography (Caveat, Indie Flower, Permanent Marker)
     • Ink splatter and brush stroke accents
     • Paper card styling with torn edges
     • Animated elements (floating paper, drawing lines)
