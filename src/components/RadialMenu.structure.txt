┌─────────────────────────────────────────────────────────────────────────────┐
│ Positioning Mathematics                                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  Starting Angle: -90° (top of circle)                                       │
│  Angle Step: 360° / 7 = 51.43°                                              │
│                                                                              │
│  For each item i:                                                           │
│    angle = (-90 + 51.43 × i) × (π / 180)                                   │
│    x = cos(angle) × radius                                                  │
│    y = sin(angle) × radius                                                  │
│                                                                              │
│  Item Positions (radius = 180px):                                           │
│    Item 0: angle = -90°   → (0, -180)                                       │
│    Item 1: angle = -38.57° → (140, -112)                                    │
│    Item 2: angle = 12.86°  → (175, 40)                                      │
│    Item 3: angle = 64.29°  → (78, 162)                                      │
│    Item 4: angle = 115.71° → (-78, 162)                                     │
│    Item 5: angle = 167.14° → (-175, 40)                                     │
│    Item 6: angle = 218.57° → (-140, -112)                                   │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ Animation Timeline (Framer Motion)                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  Opening Sequence:                                                           │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ 0ms      │ Container fade + scale                                   │   │
│  │          │ opacity: 0 → 1, scale: 0.8 → 1                           │   │
│  │          │ duration: 300ms                                           │   │
│  ├──────────┼──────────────────────────────────────────────────────────┤   │
│  │ 0ms      │ Item 0 appears (stagger: 0ms)                            │   │
│  │ 50ms     │ Item 1 appears (stagger: 50ms)                           │   │
│  │ 100ms    │ Item 2 appears (stagger: 100ms)                          │   │
│  │ 150ms    │ Item 3 appears (stagger: 150ms)                          │   │
│  │ 200ms    │ Item 4 appears (stagger: 200ms)                          │   │
│  │ 250ms    │ Item 5 appears (stagger: 250ms)                          │   │
│  │ 300ms    │ Item 6 appears (stagger: 300ms)                          │   │
│  │          │ Each item: opacity + scale + position                    │   │
│  │          │ duration: 400ms, ease: cubic-bezier(0.34,1.56,0.64,1)   │   │
│  └──────────┴──────────────────────────────────────────────────────────┘   │
│                                                                              │
│  Hover Effect (per item):                                                   │
│    • Scale: 1 → 1.15                                                        │
│    • Rotate: 0° → -5° → 5° → 0° (wiggle)                                   │
│    • Duration: 300ms                                                        │
│                                                                              │
│  Closing Sequence:                                                           │
│    • Container fade + scale                                                 │
│    • opacity: 1 → 0, scale: 1 → 0.8                                        │
│    • duration: 200ms                                                        │
│                                                                              │
│  Reduced Motion:                                                             │
│    • All durations: 0ms (instant transitions)                               │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

│  ────────────────────────┼──────────────────────────────────────────────   │

│  ────────────────────────┼──────────────────────────────────────────────   │

│  ────────────────────────┼──────────────────────────────────────────────   │

│  ────────────────────────┼──────────────────────────────────────────────   │

│  ────────────────────────┼──────────────────────────────────────────────   │
│  Hover Item               │  → Scale + rotate animation                     │
│  ────────────────────────┼──────────────────────────────────────────────   │
│  Tab Key                  │  → Sequential focus through items               │
│  ────────────────────────┼──────────────────────────────────────────────   │

│                           │  → Close menu                                   │
